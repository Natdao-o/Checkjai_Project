# CheckJai (เช็คใจ) 🌷

**ฟีเจอร์ครบแล้วสำหรับวันนี้** — รายงานความคืบหน้าของโปรเจกต์เพื่อการดูแลสุขภาพใจของนักศึกษา

## 1. ภาพรวมโปรเจกต์ (Project Overview)
**CheckJai (เช็คใจ)** เป็นเว็บแอปพลิเคชันที่ออกแบบมาเพื่อเป็นพื้นที่ปลอดภัยสำหรับนักศึกษา ในการสำรวจสภาวะจิตใจ ระบายความรู้สึก และฟื้นฟูพลังบวกผ่านกิจกรรมต่างๆ ที่ผ่านการคัดสรรมาอย่างอ่อนโยน

## 2. ฟีเจอร์ที่เพิ่มเข้ามาใหม่ (Latest Updates)

### 🦋 จดหมายฟองสบู่ (Bubble Letter)
*   **พื้นที่ระบายความรู้สึกแบบส่วนตัว**: ออกแบบมาเพื่อความเป็นส่วนตัวสูงสุด (Privacy-focused)
*   **ความปลอดภัยของข้อมูล**: ระบบไม่มีการบันทึกข้อความลงฐานข้อมูล เพื่อให้ผู้ใช้งานสามารถปลดปล่อยความรู้สึกได้อย่างสบายใจไร้กังวล

### 🌷 โปสการ์ดรอยยิ้ม (Smiling Postcard)
*   **คลังเพลงฮีลใจ (Healing Music)**: ระบบรองรับการสลับภาษา (Thai/English) และเชื่อมต่อกับ YouTube เพื่อให้เข้าถึงบทเพลงที่ช่วยปลอบประโลมใจได้ทันที
*   **การ์ดเรื่องเล่าสร้างแรงบันดาลใจ**: รวบรวม 8 เรื่องราวพลังบวกผ่านระบบ Modal Interaction ที่สวยงามและใช้งานง่าย

### 💐 กิจกรรมฮีลใจ (Heal Jai Activities)
*   **แหล่งรวมกิจกรรมคลายเครียด**: เชื่อมต่อกับแหล่งเรียนรู้และพักผ่อนภายนอก
    *   **Let's draw it**: พื้นที่สำหรับการวาดรูปและสร้างสรรค์งานศิลปะ
    *   **CrazyGames**: เกมผ่อนคลายเบาสมองเพื่อการพักพักหย่อนใจ

## 3. รายละเอียดทางเทคนิค (Technical Stack)
โปรเจกต์พัฒนาด้วยเทคโนโลยีที่ทันสมัยและมีประสิทธิภาพ:
*   **Frontend**: React (Vite) เพื่อความรวดเร็วในการประมวลผล
*   **Styling**: Tailwind CSS สำหรับการออกแบบ UI ที่ยืดหยุ่นและสวยงาม
*   **Backend & API**: เชื่อมต่อการรับส่งข้อมูลผ่าน API บน Render

## 4. สถานะปัจจุบัน (Current Status)
สถานะ: **Ongoing Development** 🏗️
โปรเจกต์ยังคงอยู่ในช่วงการพัฒนาและปรับปรุงอย่างต่อเนื่อง เพื่อเพิ่มฟีเจอร์ใหม่ๆ และสร้างประสบการณ์การใช้งานที่สมบูรณ์ที่สุดสำหรับนักศึกษา
